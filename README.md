### Ep.6 End of Mercy

ท่ามกลางหิมะสีดำที่โปรยปราย
ร่างของน้องจิ้งจอกล่องลอยอยู่ท่ามกลางจักรวาลหลายแห่ง
สิ่งที่เขามองเห็นเพียงอย่างเดียวนั่นคือ… คือร่างไร้ชีวิตของบอสจากโลกคู่ขนาน

“ไม่ว่าโลกไหน… บอสก็ต้องตายใช่ไหม…”

เขาทรุดลง เสียงหัวเราะค่อยๆเปลี่ยนเป็นเสียงสะอื้น
ความจริงที่โหดร้าย — พลังที่เขาใช้ สามารถมอบทุกอย่าง เว้นเพียงสิ่งเดียวที่เขาต้องการ

นั่นคือร่างที่มีชีวิตชีวาของบอสคนเดียวที่เค้าเคารพและนับถือ

เจ้าจิ้งจอกได้กวาดสายตาไปเรื่อยๆแบบไม่มีจุดหมาย

ทว่าในเงามืดนั้น เจ้าจิ้งจอกเห็นบางสิ่งบางอย่างที่เคลื่อนไหว…

เงาร่างมหึมาผุดขึ้นจากก้นบึ้งของจักรวาล —
มันคือ “รากเหง้าแห่งความจริง” เทพเจ้าที่ควบคุมเส้นเวลา
มันเสนอสิ่งหนึ่ง… แลกกับการ “ลืมทุกอย่าง”

“หากเจ้ายอมสละจิตใจ… ข้าจะมอบโลกใหม่ให้เจ้าทุกครั้งที่เจ้าปรารถนา”

น้องจิ้งจอกมองทุกสิ่งทุกอย่างรอบตัว — มืดสนิท ไม่มีดวงดาว ไม่มีหวัง
สุดท้าย เขายิ้ม… ครั้งสุดท้าย

“ถ้าโลกต้องแลกด้วยจิตใจ… งั้นข้าจะสร้างโลกที่ไม่มีหัวใจเลยซักดวง”

เขาเดินเข้าสู่รากเหง้าแห่งความจริง ดวงตาสีเงินดับลง
จักรวาลทั้งมวลค่อยๆพังทลาย กลืนสู่ความว่างเปล่า
