### Ep.5 The Riftborn

เสียงกระซิบของอดีต ยังหลอกหลอนกลางเสียงกรีดร้องของโลกที่แตกสลาย
น้องจิ้งจอกยืนอยู่บนซากเมืองที่ถูกไฟลุกไหม้ เส้นแสงสีเงินยังคงส่องจากดวงตา
เขารู้ดี… พลังนี้ไม่ใช่ของมนุษย์อีกต่อไป

ด้วยพลังแห่งโลกคู่ขนาน เขาเดินข้ามเส้นเวลา
ไปยังอีก “โลกหนึ่ง” ที่แก๊งสารเลวเพิ่งก่อตั้ง
ที่นั่น... บอสของเขายังมีชีวิต และยังยิ้มให้เขาเหมือนเดิม

แต่นี่ไม่ใช่การกลับบ้าน — เพราะโลกนี้ก็เต็มไปด้วยความโสมมเหมือนโลกเดิม
และตัวเขา… ก็ไม่ใช่ผู้เฝ้ามองอีกต่อไป

“นายคือ ‘รอยแยก’ ระหว่างจักรวาล…
นายคือความผิดพลาดที่โลกนี้พยายามกลบฝัง…”

เหล่าผู้พิทักษ์จักรวาล ปรากฏตัวจากเงามืด
พวกเขาคือสิ่งมีชีวิตไร้กาลเวลา สวมหน้ากากสีขาว พูดด้วยเสียงรวมจากวิญญาณนับพัน

“หากไม่สังหาร ‘รอยแยก’ โลกจะพังลงทั้งหมด…”

แต่น้องจิ้งจอกหัวเราะ ใบหน้าบิดเบี้ยวด้วยความแค้นและความเศร้า

“ถ้าจะพัง… ก็พังไปพร้อมกับพวกแก!”

เขาเรียกดาบสีดำสนิทที่สร้างจากเศษกระจกแห่งอนาคต
และต่อสู้กับเหล่าผู้พิทักษ์อย่างบ้าคลั่ง — เลือดสีฟ้าไหลเป็นทาง

สงครามครั้งแรกของจักรวาล เริ่มต้นแล้ว…
